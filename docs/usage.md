# 图形块作业使用指南

## 启动与快速演示

双击根目录 Start-QCAD.cmd。若提示缺少编译产物，按 README 执行 setup-qt.ps1 和 build.ps1。环境及 SDK 位于本项目 build/，无需激活 lerobot。

打开 examples/block-demo.qbl，可看到原始的矩形、圆与中文 Text，以及同一块的两个实例。选择“插入块”，可继续插入“设备组合”。

## 从零完成一次作业

1. 新建文件，绘制一个矩形和一个圆；使用 Text 工具单击两个角点，在弹窗中输入文字。
2. 按 Esc，再拖出矩形框完全包围这三个图元。Shift 可追加选择，Shift 单击已选图元可取消该图元；Ctrl+A 选择全部。
3. 点击第二行工具栏的“定义块”，输入“设备组合”，再点击矩形某一角作为基点。定义不会删除或移动原图形。
4. 点击“插入块”，从列表中选择“设备组合”，设置旋转角度和等比缩放。正角度为世界坐标逆时针，缩放 1 表示原尺寸，变换围绕插入基点。移动鼠标可看到预览；单击落下一个实例，继续单击可重复插入。按 Esc 或右键退出。
5. 如需编辑 Text，选择文字后直接双击即可打开编辑窗口，也可以点击“Text 属性”或按 Ctrl+E。内容支持中文和多行；字体下拉框列出本机可用字体，可直接输入字体名；字号支持小数和 0.1–10000 pt 范围；还可更改粗体、斜体、下划线、颜色以及文本框 X/Y/宽/高。X/Y 使用世界坐标，Y 是文本框较小的 Y 值。
6. Ctrl+S 保存为 .qbl，Ctrl+Shift+S 另存。重新打开该文件后可继续选择、移动、删除和插入。

修改原 Text 不会回写已经定义的块；需要新版本组合图形时，以新块名再次定义。

编辑块内文字：选中一个块实例，点击“Text 属性”或 Ctrl+E，从层级路径列表选择文字，再编辑属性。位置和尺寸使用该文字经过块旋转/缩放之前的坐标；屏幕上仍会应用所属各层的变换。修改只作用于当前实例，不改变定义或其他实例，保存重开后保留。

嵌套块：选择已有块实例及其他图元，再“定义块”。子块的现有位置、旋转、缩放和文字修改均复制为独立快照。可以继续组合；嵌套深度最多 32 层。

## 基本交互

| 操作 | 使用方式 |
| --- | --- |
| 选择 | Esc 返回选择；单击一个图元，或按住左键拖框 |
| 追加选择 | 按住 Shift 单击或拖框 |
| 全选 | Ctrl+A |
| 定义块 | 选择多个图元 → 定义块 → 名称 → 在画布选基点 |
| 插入 | 插入块 → 选名称 → 旋转/缩放 → 预览 → 左键提交；Esc/右键结束 |
| 块变换 | 选中一个块 → 块旋转/缩放 → 确定 |
| 文本属性 | 双击独立 Text；选中块后按 Ctrl+E 可选择内部文字 |
| 移动 | 先选择图元/块 → 移动工具 → 起点 → 目标点 |
| 鼠标拖动 | 普通图元和块均可；在已选图形内部按住左键 → 移动 → 松开，多选时一起移动 |
| 滚轮缩放 | 以鼠标位置为中心，向上放大、向下缩小；比例范围 1%–10000% |
| 画布平移 | 按住鼠标中键移动 |
| 删除 | 选择后按 Delete，或点击删除工具 |
| 取消 | Esc 返回选择状态，取消未提交预览；已插入实例保留 |
| 保存/打开 | 文件菜单或 Ctrl+S / Ctrl+O |

块作为整体参与点选、框选、移动和删除。旋转和缩放作用于所有子图元及文字；嵌套时逐层组合变换。框选使用变换后轴对齐包围盒，可能包含空白区域。

拖动时超过系统阈值才显示预览，松开提交。小幅点击抖动不移动；Esc、右键或切换工具取消，原位置和已有修改状态保持不变。旋转/缩放后的普通图形、块及嵌套块都能拖动。空白处仍为框选，Shift 点选/拖框改变选择。滚轮缩放会取消尚未提交的拖动，避免缩放期间误移动图形。

## 常用图形编辑

“编辑”菜单提供 Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴、Ctrl+D 快速复制、Ctrl+Z 撤销，以及 Ctrl+Y / Ctrl+Shift+Z 重做。复制与粘贴保留完整样式、变换及块内文字；块粘贴到新文档时会带入定义，实例 UUID 重新生成。重复粘贴错开位置。剪贴板是 QCAD 图元数据，不支持与 PowerPoint 直接交换原生对象。

方向键移动当前选择集一个世界单位，Shift+方向键移动十个单位。Delete 删除，可撤销。撤销同时恢复图元、图层顺序、选择及块库；最多保留 100 次编辑。打开或新建文档清空历史，保存标记当前历史位置；撤销回保存位置后，修改标记自动清除。

“排列”菜单提供：

- 组合（Ctrl+G）：至少选择两个图元，将它们变为一个整体，支持嵌套；与“定义块”保留原件不同，组合会替换选中的原件。
- 取消组合（Ctrl+Shift+G）：拆出一层子图元，保留在画布上的位置、旋转、缩放、翻转和文字属性。
- 旋转 / 缩放：围绕选择集包围盒中心，设置旋转增量和等比缩放倍率；也可左右旋转 90°、水平或垂直翻转。普通图元类型保持不变。
- 左/中/右、上/中/下对齐：至少两个对象，按选择集的外包围盒对齐；对齐顶端表示屏幕上方（世界 Y 较大）。
- 水平/垂直等距分布：至少三个对象，按包围盒边缘间距分布，保持首尾位置。
- 置顶 / 置底：改变绘制及点选优先级，保留选中对象的相对顺序。

选中图形后，已有填充、线条颜色、线宽、线型工具会应用到选择集；字体工具应用到选中的文字，包括块内文字。均可撤销。文字属性中的位置和尺寸仍采用变换前坐标。

## 存储内容

.qbl v3 保存普通图元和块的仿射变换、样式、定义、实例 UUID、递归子图元及内部文字修改。兼容 v1/v2，再次保存写为 v3；旧程序不能读取 v3。图元载荷新增可识别的变换扩展，旧载荷默认为单位变换。保存采用 QSaveFile 原子替换，加载完整校验后替换文档；损坏文件保留当前图形。视图缩放和平移不改变图元世界数据，不进入撤销记录；撤销历史和剪贴板不写入文件。

打开其他文件、新建或关闭含未保存修改的文档，会提示保存、放弃或取消。磁盘保存失败不会显示为已保存。

## 删除开发环境

关闭程序后，将个人 .qbl 文件放在 examples/ 或其他非 build 目录。可先使用 Conda 的 env remove 删除 build/qt-dev 登记，再删除 build/，不需要卸载系统 Visual Studio，也不影响 lerobot。重新开发时重新运行 setup-qt.ps1 和 build.ps1。
