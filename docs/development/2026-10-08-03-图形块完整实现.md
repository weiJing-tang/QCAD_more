## 关键决策与开源复用

采用用户本地 ../QCAD/QCAD，未替换为另一套 CAD 框架。源文件校验值及编码已记录在 docs/provenance/course-source.json。已有 Qt 示例版权头保留；课程整体无可核实的上游 commit 或统一许可证，不虚构来源。

沿用 C++14、Qt 值类型、MEntity、MText 和 QCADView。下载 Qt 5.15.2 基础开发包、安装 aqtinstall 3.3.0 作为辅助工具；工具来源和元数据见 provenance/README.md。

原工程依赖失效的 Qt/Visual Studio 机器路径，改由 CMake 编译实际使用的课程源码。初次发现静态库与应用目标仅大小写不同，在 Windows 下产生循环依赖，已将库重命名为 qcad_more_core。

环境使用 build/qt-dev 下独立 Conda Python 3.11，以及 build/Qt 下 SDK。之前仅借用 lerobot 的 Python 建立过临时隔离工具目录，未向 lerobot 安装依赖；临时目录已删除。后续构建运行不依赖该环境。
