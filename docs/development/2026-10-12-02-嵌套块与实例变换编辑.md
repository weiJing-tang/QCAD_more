# 开发记录：嵌套块与实例变换编辑

- 日期：2026-10-12
- 状态：已完成

## 目标

按用户澄清，扩展块内文字编辑、旋转缩放及嵌套块，同时补足原测试的局限。

## 实际修改

- 递归块快照支持嵌套定义，原图形及定义保持独立。
- 插入时及选中已有实例后可设置基点旋转和等比缩放；绘图、包围盒、移动使用一致的变换。
- Text 属性入口支持按层级路径选择块内文字，仅修改当前实例。
- qbl 升级为 v2，保存递归实例快照及文字修改，继续读取旧 v1。
- 扩展七类图元完整往返、缩放选择、取消编辑、格式破损、嵌套变换与实例文字编辑测试；增加 Windows 原生 QPA 验证。
- 修复 GetBox 重复计算首个子块的问题，避免深层嵌套出现指数级递归；32 层正常往返，33 层被拒绝。

## 关键决策与开源复用

复用现有 Qt 5.15.2 QTransform、QPainter、QDataStream、QSaveFile、属性对话框和图元编解码；不引入新库。递归内容为自包含快照，没有循环引用。保留原几何坐标，在绘制时组合父子变换，避免修改各图元算法导致椭圆/矩形/文字旋转失真。编解码限制 32 层。

执行 scripts/build.ps1 -Check：Release 构建成功，CTest 2/2 通过；offscreen 与 Windows 原生 QtTest 各 13 passed、0 failed、0 skipped。新增验证包括旋转线条实际像素位置、嵌套父子变换组合、块内 Text 修改不影响其他实例、已有实例变换保存恢复、32/33 层边界、旧 v1 读取、编辑取消和格式损坏保护。

检查 Windows 原生生成的 rotated-block.png 与 nested-block-workflow.png，旋转方向、缩放及新菜单可见。原生鼠标悬停测试使用 Qt QMouseEvent 投递，避免弹窗后的系统光标移动合并；拖框、点击、双击仍由 QtTest 驱动。两种字体后端字形度量不同，像素断言选择不被文字覆盖的线段，避免字体差异导致误报。
