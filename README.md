## 开发入口

开发前必须阅读 [AGENTS.md](AGENTS.md)。项目要求：

- 使用 C++ 或 C，沿用合适的现有工程组织方式。
- 优先复用成熟的 GitHub 开源实现，核对许可证和版本。
- 保持实现简单、职责清晰，避免重复代码与过度设计。
- 按风险集中验证，不频繁重复测试，不追逐不可能出现的边界条件。
- 每次开发必须在 [docs/development/](docs/development/) 留下开发记录。
